# The rule makes the move the user names

Status: ready-for-agent
Blocked by: nothing

## What it produces

The `## Stochastic seams` section that `setup` writes into `AGENTS.md`, rewritten on decision 15 in `CONTEXT.md`:

- A move the user names in the request is made: the agent amends the charter's line, makes the change and says so in its answer. A ticket, plan or draft an agent wrote does not name a move, even once approved.
- A line the request did not name stays where it is. The agent asks before moving it only when the request cannot be met at all without the move; when moving it is only easier or better, it asks nothing and leaves the line.
- "Only the user changes a charter" and "never edit the charter" go: the agent edits it, and only for a move the user named.

The rest of the rule, what moves a line and the spending rules, stays as it is.
