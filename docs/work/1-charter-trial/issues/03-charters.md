# One charter per seam

Status: ready-for-human
Blocked by: 02

## What it produces

`trials/charters/<seam>.md` for each of the four seams: what the model is free to decide, what code constrains, and why.

The charter is the treatment under test, and it is also the measure: drift is always a move against a written line, so the charter is what a change is judged against in both conditions.

## Who writes it

The user, with the `charter` skill, one seam per session. It is the skill's first real use, so note where it got in the way.

## The one rule

The charter is written from the seam's code and `README.md`, before the user reads that seam's requests. A charter written knowing the requests would be cut to fit them.

## Done when

- Four charters exist, each confirmed by the user.
- Notes on the `charter` skill, if any, are in `openpoints.md`.
